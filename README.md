# Relief Route AI

Update the current website hero section and replace the existing decorative painting/background image with a problem-specific visual for our hackathon problem statement:



PROBLEM TITLE:

"The Paralyzed Relief Supply Chain"



PROBLEM SCENARIO:

Following an earthquake that triggers widespread hillside debris flows combined with overflowing river tributaries, primary arterial highways and rural feeder roads become hazardous. Several bridges suffer structural damage and are unsafe for heavy vehicles, while key intersections are submerged under varying depths of fast-moving water.



Fleets carrying critical relief materials such as infant nutrition, insulin, blood bags, and potable water depart from regional storage hubs, but conventional GPS and map systems continue routing them onto damaged or submerged roads.



Supply convoys become stranded, waste critical hours turning back, or end up trapped in dynamic flash-flood zones, leaving isolated relief shelters without essentials for days.



DESIGN CHANGE:

1. Remove the current landscape/painting image completely.

2. Replace it with a cinematic but professional disaster-relief supply-chain illustration.

3. The visual should show:

   - Earthquake-damaged mountainous/hilly terrain

   - Landslide/debris flow blocking a major road

   - A partially damaged bridge marked unsafe

   - Flooded road intersections with flowing water

   - Relief trucks/ambulances carrying emergency supplies

   - Isolated relief shelters on the other side

   - A regional relief warehouse/storage hub

   - A few vehicles visibly stranded or forced to turn back

   - A subtle indication that the conventional route is unsafe

4. Add a visual contrast between:

   - RED/ORANGE = blocked, flooded or dangerous roads

   - GREEN/BLUE = safe alternative routes

5. Include subtle digital-map/routing elements over the scene so the visual connects the disaster scenario with an AI-powered routing solution.

6. Do NOT make it look like a generic disaster poster. It should look like a modern AI/technology product website.

7. Keep the visual sophisticated, minimal and premium, similar to a high-end AI SaaS landing page.

8. Avoid excessive text inside the image.

9. Do not use random stock-photo-looking imagery.

10. The image should blend naturally with the existing website's black, white and neon-green visual identity.



HERO SECTION:

Keep the existing HackerRank-inspired visual hierarchy, but adapt the content to our problem.



Replace the current hero heading with:



"The Paralyzed Relief Supply Chain"



Add a short subtitle:



"When roads fail, conventional GPS fails too. AI must dynamically reroute critical relief supplies through safe, accessible paths."



Add a primary CTA:

"Explore the Solution"



Add a secondary CTA:

"View Problem"



Below/around the hero visual, subtly highlight:

"Damaged Roads • Flooded Intersections • Unsafe Bridges • Stranded Relief Convoys"



IMPORTANT:

The visual must make the problem immediately understandable without reading the full description.



Do NOT change the entire website architecture or unrelated sections. Preserve the existing navbar, typography, animations, responsiveness and overall design system unless required for the new hero section.



Make the final result fully responsive for desktop, tablet and mobile.



Use a high-quality generated/vector-style illustration if possible. If image generation is unavailable, create the visual using CSS/SVG/HTML elements rather than inserting a random stock image.



The final website should feel like an AI-powered emergency logistics platform rather than a generic disaster-management website.
